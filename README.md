# Индвидуальный проект Система личного календаря

---
## Назначение проекта

Проект представляет собой  приложение для управления личными событиями и задачами. Система позволяет пользователям создавать, хранить и отслеживать свои планы, встречи и напоминания в структурированном виде. Основная цель — помочь пользователю эффективно организовывать свое время.

---

## Целевая аудитория

1. Студенты и школьники
2. Работающие специалисты
3. Люди, стремящиеся к повышению продуктивности и контролю собствен6ного времени.

---
## ПРедметная область

Предметная область — управление временем. В современном мире люди сталкиваются с большим потоком информации и задач. Система личного календаря выступает в роли цифрового помощника, который берет на себя функцию учета событий. Работа с календарем строится вокруг понятий даты, времени и приоритета, что позволяет пользователю не держать всю информацию в голове.

---

## Основная сущность

1. Событие.
2. Даты и время (дедлайны).
3. Приоритетность задач.

---

## Возможности

1. Создание события (ввод названияЮ даты дедлайна, времени и приоритета выполнения)
Создание события осуществляется путем ввода дела, которое необходимо выполнить, дедлайна выполнения и опционально установки приоритетности выполнения.
2.  Просмотр списка задач.
Просмотр списка задач осуществляется путем вывода на экран вспех задач, внесенных в куда-то там.
3. Редактирование уже созданных задач.
В функции редактирования задачи можно измениь установленные дедлайн, описание или приори тетность выполнения.
4. Отметки выполенненных задач и удаление созданных по ошибке.
Отметка выполнения задачи на данный момент осущеситвляется с помощью установки флага. При установки флага выполнения задача отправлется в корзину.

## Структура проетка

## Структура проекта
- `main.py` — точка запуска, меню;
- `storage.py` — загрузка и сохранение JSON;
- `utils.py` — вспомогательные функции ввода;
- `models/` — пакет классов:
  - `events.py` — Event и функции работы с событиями;
  - `users.py` — User и функции работы с пользователями;
  - `priorities.py` — Priority и функции работы с приоритетами;
- `data/` — JSON-файлы;
- `tests/` — автоматизированные тесты.

---

## Требования
- Python 3.x;
- pytest;
- flake8.

Установка зависимостей:
pip install -r requirements.txt

## Запуск программы
python main.py
## Запуск тестов
python -m pytest tests/ -v
## Проверка качества кода
python -m flake8
